# Intercom-Inspired Design Guide

## Visual Theme
- Friendly, conversational, support-oriented UI.
- Soft blue gradients and high legibility.
- Rounded surfaces for approachable interactions.

## Colors
- Primary: `#1F6FFF`
- Primary Hover: `#0F4FD6`
- Surface: `#FFFFFF`
- Background: `#F3F7FF`
- Message Surface: `#F8FBFF`
- Border: `#D8E6FF`

## Typography
- Font Family: Nunito Sans, Pretendard fallback
- Headings: extra-bold
- Body: clear, medium contrast

## Components
- Buttons: pill radius, strong primary fill
- Cards/Panels: subtle soft shadow, rounded corners
- Status chips: compact and glanceable
- Message logs: chat-like bubbles with timestamp captions

## Layout
- Left control rail (sidebar)
- Main workspace with 3 blocks:
  1. Run summary
  2. Live agent status + progress
  3. Tabbed conversation/tool/report view

## Motion
- Keep motion minimal and purposeful.
- Progress bar updates on stream events.

## Responsive
- Sidebar remains primary control surface.
- Main panels stack vertically under narrow widths.
